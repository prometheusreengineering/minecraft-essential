## Features
- Unlocks ALL cosmetics and emotes.
- Dumps ALL cosmetics and emotes data into `.minecraft/prometheus/essential/dumps`.
- Lightweight and non-invasive.
- Compatible with *almost* all versions of Essential Mod.

### Legacy (Removed) Cosmetics
Some cosmetics previously offered by Essential are no longer available. We have no way of unlocking those cosmetics unless we have the [cosmetic ID](src/main/resources/cosmetics.json). If you have more cosmetic IDs that we don't have, please consider [contributing](CONTRIBUTING.md)!
