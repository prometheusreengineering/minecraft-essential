# minecraft-essential

The Prometheus' patch for Essential Mod.

[![Download Count](https://img.shields.io/github/downloads/prometheusreengineering/essential/total?style=for-the-badge)](https://github.com/prometheusreengineering/essential/releases/)
[![Discord](https://img.shields.io/discord/1197794960985043034?style=for-the-badge&label=Discord&color=rgb(88%2C%20101%2C%20242)%20)](https://discord.gg/BFDWmPfmXg)

## Compatibility

| Loader   | Versions            |
|:---------|---------------------|
| Forge    | 1.8.9-1.12.2, 1.18+ |
| Fabric   | 1.16+               |
| NeoForge | 1.20+               |

Download the mod [here](https://github.com/prometheusreengineering/minecraft-essential/releases/latest), or use
our [loader](https://github.com/prometheusreengineering/prometheus-minecraft/releases/latest) for auto-updates.

## Features

- Unlocks ALL cosmetics and emotes.
- Dumps ALL cosmetics and emotes data into `.minecraft/prometheus/essential/dumps`.
- Lightweight and non-invasive.
- Compatible with *almost* all versions of Essential Mod.

### Legacy (Removed) Cosmetics

Some cosmetics previously offered by Essential are no longer available. We have no way of unlocking those cosmetics
unless we have the [cosmetic ID](src/main/resources/cosmetics.json). If you have more cosmetic IDs that we don't have,
please consider [contributing](CONTRIBUTING.md)!
